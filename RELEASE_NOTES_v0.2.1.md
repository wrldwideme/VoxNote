# VoxNote v0.2.1 — Хотфикс: закрытие окна и доустановка GPU NVIDIA из настроек

В этом хотфиксе исправлена проблема с закрытием окна приложения и добавлена возможность доустановить пакет CUDA-ускорения NVIDIA прямо из интерфейса.

## Что нового и исправлено:

- **Исправлена кнопка закрытия окна (крестик)**: в разрешения Tauri 2 добавлены `core:window:allow-destroy` и `core:window:allow-close`, а также прямой системный вызов. Окно закрывается штатно, а во время активной транскрибации появляется диалог с предложением безопасно остановить запись и сохранить уже распознанный текст.
- **Доустановка GPU NVIDIA из интерфейса**: если пользователь на стартовом экране выбрал только лёгкий CPU-движок, теперь в любой момент в «Настройках» (Шестерёнка) доступна кнопка **«Установить GPU»** (~667 МБ). Загрузка пакета CUDA идёт напрямую с GitHub с отображением процентов, проверкой SHA-256 и безопасным перезапуском ML-ядра без закрытия интерфейса.
- **Стабилизация автосохранения**: устранён потенциальный сбой `TypeError` при асинхронном сохранении заметок.
- **Улучшения тестов и CI**: исправлены задержки фокуса в редакторе конспекта в headless-окружении GitHub Actions.

## Что скачать

- `VoxNote_0.2.1_x64-slim-setup.exe` — рекомендуемый лёгкий установщик (~6,09 МБ).
- `VoxNote-0.2.1-Windows-x64-CPU-Portable.zip` — портативная версия только для процессора.
- `VoxNote-0.2.1-Windows-x64-Full-NVIDIA-Portable.zip` — полная портативная версия с CUDA-ускорением.
