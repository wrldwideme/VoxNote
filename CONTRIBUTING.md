# Участие в разработке VoxNote

Спасибо за интерес к проекту.

## Перед началом

1. Прочитайте `PROJECT_SPEC.md`.
2. Прочитайте `IMPLEMENTATION_PLAN.md`.
3. Соблюдайте правила `AGENTS.md`.
4. Выберите задачу текущего этапа и согласуйте изменения scope заранее.

## Локальная проверка

Перед pull request выполните:

```powershell
python -m pytest
python -m ruff check .
python -m ruff format --check .
python -m mypy src
```

## Приватность

Не прикладывайте к issue и pull request пользовательские аудиофайлы, расшифровки, словари, логи с абсолютными путями или API-ключи. Тестовые записи должны иметь понятное происхождение и лицензию.

## Большие файлы

Не добавляйте в Git веса моделей, установочные архивы, сгенерированные сборки и реальные пользовательские записи.
