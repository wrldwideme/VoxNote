# VoxNote v0.2.2 — стабильность транскрибации и runtime

Этот patch-релиз устраняет гонки между интерфейсом, Python-sidecar и установщиком runtime, защищает активную транскрибацию от случайного прерывания и улучшает восстановление локальных данных.

## Что исправлено

- активную транскрибацию больше нельзя скрыть переходом к новому файлу, истории, настройкам или обновлению приложения;
- первый запуск повторяет подключение до фактической готовности Python-sidecar;
- перезапуск sidecar после установки NVIDIA-пакета защищён от гонки со старым watchdog-потоком;
- IPC-клиент регистрирует единственный слушатель даже при параллельных стартовых запросах;
- системный drag-and-drop Tauri корректно передаёт абсолютный путь аудиофайла;
- `100%` отображается только после успешного сохранения итоговой расшифровки;
- история синхронизирует конкурентные изменения и сохраняет резервную копию повреждённого JSON;
- неполный NVIDIA runtime больше не считается установленным;
- повтор на CPU предлагается только для ошибок GPU/CUDA;
- исправлены гонка результатов поиска и ложное предложение установить более старую версию.

## Файлы релиза

- `VoxNote_0.2.2_x64-slim-setup.exe` — рекомендуемый лёгкий установщик;
- `VoxNote-0.2.2-Windows-x64-CPU-Portable.zip` — портативная CPU-версия;
- `VoxNote-0.2.2-Windows-x64-Full-NVIDIA-Portable.zip` — полная портативная версия с CUDA;
- `latest.json` и `.sig` — подписанные метаданные встроенного обновления.

Модели распознавания не входят в дистрибутив. Slim-установщик предлагает загрузить CPU-runtime или CPU + NVIDIA после явного выбора пользователя.
