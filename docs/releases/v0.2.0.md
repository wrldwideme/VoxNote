# VoxNote v0.2.0 — лёгкое приложение и раздельный ML-runtime

VoxNote больше не заставляет повторно скачивать CUDA и Python-движок при каждом обновлении интерфейса. Приложение, CPU-runtime и ускорение NVIDIA теперь распространяются отдельно.

## Главное

- slim-установщик уменьшен с 609 МБ до 6,08 МБ;
- при первом запуске пользователь явно выбирает CPU или NVIDIA;
- CPU/core runtime скачивается один раз и занимает 88,23 МБ в архиве;
- NVIDIA pack размером 667,37 МБ нужен только владельцам совместимой видеокарты;
- загрузка показывает реальный прогресс, отменяется и проверяется по SHA-256;
- runtime активируется только после успешной безопасной распаковки;
- обновления проверяются автоматически, но скачиваются и устанавливаются только после подтверждения;
- подписанный Tauri updater обновляет оболочку, не затрагивая модели, историю и тяжёлый runtime.

Релиз также включает исправления транскрибации, аварийное восстановление и продолжение частичного результата, полноценные словари без обрезки до 30 терминов, настоящий редактор и историю версий, новый Home, улучшенный прогресс и ETA, reduced motion и проверку перепривязки аудио.

## Что скачать

- `VoxNote_0.2.0_x64-slim-setup.exe` — рекомендуемый установщик. После запуска предложит CPU или NVIDIA.
- `VoxNote-0.2.0-Windows-x64-CPU-Portable.zip` — переносимая CPU-версия без дополнительной загрузки runtime.
- `VoxNote-0.2.0-Windows-x64-Full-NVIDIA-Portable.zip` — полная переносимая версия с CUDA-ускорением.

Модели распознавания по-прежнему не входят в дистрибутив и устанавливаются отдельно по выбору пользователя.
