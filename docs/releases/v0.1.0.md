# VoxNote v0.1.0 — Первый публичный релиз (MVP)

🎉 **VoxNote** — открытое Windows-приложение для полностью локальной офлайн-транскрибации русскоязычных аудиозаписей, ориентированное на конспектирование лекций, вебинаров, докладов и медицинских аудиозаписей.

---

## 🌟 Главные возможности v0.1.0

- 🔒 **100% локальная приватность и нулевая телеметрия:**
  - Ваши аудиозаписи, словари и распознанный текст никогда не отправляются в интернет.
  - Никакой скрытой аналитики, трекеров или crash-reporting SDK.
  - Сетевая активность полностью заблокирована во время транскрибации.

- ⚡ **Высокопроизводительное ядро (faster-whisper + CUDA 12):**
  - Поддержка аппаратного ускорения **NVIDIA GPU** (RTX / GTX с архитектурой Pascal и новее: cuBLAS, cuDNN 9, NVRTC).
  - Автоматическое переключение на оптимизированный CPU-движок с поддержкой многопоточности и инструкций AVX2 при отсутствии видеокарты.

- 🎨 **Современный сфокусированный интерфейс (Концепт A / Стилистика Granola):**
  - Трёхколоночная рабочая зона: библиотека записей, рабочая панель документа с предпросмотром аудиоволны и панель терминологии.
  - Поддержка светлой, тёмной и системной темы оформления.
  - Адаптация под `prefers-reduced-motion` для комфортной работы.

- ⏱ **Честный прогресс и адаптивный ETA:**
  - Прогресс рассчитывается строго по секундам декодированной речи без «фейковых» таймеров.
  - Динамический сглаженный расчет оставшегося времени (ETA).

- 🩺 **Медицинский словарь и пользовательские термины:**
  - Встроенный словарь из **1 847 проверенных медицинских и фармакологических терминов**.
  - Возможность подключать собственные `.txt` словари для специфических лекций и профессиональных терминов.

- 📁 **Гибкость в настройке путей:**
  - Выбор произвольной папки для хранения и загрузки весов моделей (`small`, `turbo`, `large-v3`).
  - Возможность выбора каталога установки приложения в стандартном мастере установки.

- 📄 **Экспорт и история:**
  - Экспорт расшифрованного текста в форматы **TXT** и **Markdown**.
  - Быстрое копирование в буфер обмена в один клик.
  - Встроенная история с поиском и фильтрацией по ключевым словам.

## 💻 Системные требования

- **ОС:** Windows 10 x64 / Windows 11 x64;
- **Процессор:** x86_64 с поддержкой инструкций AVX2 (Intel Core 4th Gen+ / AMD Zen 1+);
- **Оперативная память:** 8 ГБ RAM (рекомендуется 16 ГБ для модели `large-v3`);
- **Видеокарта (опционально для ускорения):** NVIDIA GPU с поддержкой CUDA Compute Capability >= 7.0 (GeForce GTX 16xx / RTX 20xx / 30xx / 40xx и новее);
- **Свободное место на диске:** от 2.5 ГБ (приложение) + 0.5–3 ГБ на веса моделей.

## 🚀 Быстрый старт

1. Скачайте **`VoxNote_0.1.0_x64-setup.exe`** и запустите установщик (или распакуйте **`VoxNote-0.1.0-Windows-x64-Portable.zip`**);
2. При первом запуске откроется **вводная инструкция** с кратким обзором интерфейса и горячих клавиш;
3. В окне «Модели» скачайте подходящую модель (рекомендуется **`turbo`** для оптимального соотношения скорости и качества);
4. Перетащите аудиофайл (`.m4a`, `.mp3`, `.wav`, `.flac`, `.ogg`) в рабочую область и нажмите **«Начать транскрибацию»**!
