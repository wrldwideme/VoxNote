# VoxNote v0.1.1 — Release Notes

Выпуск **VoxNote v0.1.1** устраняет все технические долги, фиктивные заглушки (mock) и превращает приложение в полностью рабочий автономный продукт.

---

## 🚀 Что нового и что исправлено

### 1. Настоящая локальная транскрибация без заглушек
* **Устранён искусственный таймер**: запуск транскрибации теперь передаёт реальный аудиофайл напрямую в headless-ядро faster-whisper через типизированный JSON-RPC.
* **Нативный выбор аудиофайлов**: интеграция с проводником Windows через нативный диалог и перетаскивание (Drag & Drop) с распознаванием форматов `.m4a`, `.mp3`, `.wav`, `.flac`, `.ogg`.
* **Честный прогресс декодирования**: расчёт процента выполнения основан исключительно на реально обработанных миллисекундах аудиозаписи (в строгом соответствии с AGENTS.md — никаких искусственных процентов).
* **Сохранение в историю**: распознанный текст автоматически записывается в `history.json` с привязкой к исходному файлу и отображается в списке лекций.

### 2. Полноценное воспроизведение аудио (HTML5 + Tauri Asset Protocol)
* Реализован аудиоплеер с поддержкой локального Tauri Asset Protocol.
* Кнопка Play/Pause запускает реальное прослушивание аудиофайла.
* Интерактивная волна (Waveform) позволяет перематывать аудио в любую точку кликом.
* Клик по любому сегменту в таймлайне мгновенно перематывает плеер на нужную секунду речи.
* Поддержка изменения скорости воспроизведения: `1x`, `1.25x`, `1.5x`, `1.75x`, `2x`.

### 3. Удаление записей из истории
* В боковую панель добавлена кнопка корзины для каждой записи с подтверждением.
* В открытую заметку добавлена кнопка «Удалить запись».
* При удалении активной записи интерфейс плавно переключается на чистый экран «Новый файл».

### 4. Очистка заметки от хардкода GoodNotes
* Удалены захардкоженные демонстрационные блоки («Краткое содержание» и «Ключевые тезисы»).
* Заметка содержит реальный распознанный текст с возможностью удобного редактирования.
* Добавлены реальные счётчики слов и символов.
* Панель инструментов Markdown: быстрое выделение жирным (`**`), курсивом (`*`), заголовком (`##`), списками (`- `, `1. `).
* Кнопка сброса к исходному распознанному тексту (`Revert to original`).

### 5. Чистый старт приложения
* При запуске VoxNote больше не загружает автоматически предыдущую запись — пользователю сразу открывается чистое окно добавления нового аудиофайла.

### 6. Система проверки обновлений
* Добавлено модальное окно «Обновление VoxNote» с проверкой свежих версий через GitHub Releases API.
* При выходе новой версии в верхней и боковой панели появляется ненавязчивый индикатор обновления со ссылками на скачивание установщика и просмотр списка изменений.

### 7. Реальное скачивание и удаление моделей
* В менеджере моделей кнопка «Загрузить» инициирует реальную загрузку модели из Hugging Face с отображением прогресс-бара и процентов.
* Добавлена кнопка отмены загрузки и возможность удаления загруженных моделей для экономии дискового пространства.
* Сохранён выбор кастомной папки для хранения весов моделей (удобно для дисков D:\, E:\).

### 8. Импорт пользовательских словарей терминов
* Кнопка «Импортировать свой словарь (.txt)» открывает нативный диалог выбора текстового файла.
* Словарь передаётся в faster-whisper как контекстная подсказка для редких медицинских или технических терминов.

### 9. Нативные элементы управления окном
* Кнопки «Свернуть», «Развернуть» и «Закрыть» в шапке окна вызывают системные команды Tauri Window.

## 📦 Пакеты для установки (Windows 10/11 x64)

1. **`VoxNote_0.1.1_x64-setup.exe`** — полноценный NSIS-установщик (создает ярлык в меню Пуск, на Рабочем столе и запись в «Установка и удаление программ»).
2. **`VoxNote-0.1.1-Windows-x64-Portable.zip`** — портативная версия без установки: распакуйте в любую папку и запустите `VoxNote.exe`.
3. **`VoxNote_0.1.1_x64_en-US.msi`** — корпоративный MSI-пакет для тихого развёртывания.

> **100% Offline & Privacy**: VoxNote не содержит телеметрии, не собирает аналитику и не отправляет аудио или текст на внешние серверы. Вся обработка происходит исключительно на вашем компьютере.
