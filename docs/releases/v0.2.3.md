# VoxNote v0.2.3 — автоматизация релизов и обновление витрины

Этот релиз переводит проект на автоматическую сборку лёгкого установщика через GitHub Actions, упрощает схему поставки и обновляет документационную витрину проекта.

## Что изменилось

- **Автоматизация релизов:** сборка подписанного slim-установщика и формирование метаданных встроенного автообновления теперь выполняются автоматически через GitHub Actions workflow `Release slim app` при отправке тега;
- **Упрощение поставки:** регулярный релиз приложения публикует только один лёгкий установщик (`VoxNote_0.2.3_x64-slim-setup.exe`), цифровую подпись (`.sig`) и манифест обновлений (`latest.json`);
- **Независимый ML-runtime:** ядро Python, faster-whisper, CTranslate2, PyAV и пакет ускорения NVIDIA поставляются через отдельный технический релиз runtime и не требуют повторной загрузки при обновлениях интерфейса;
- **Обновление витрины и документации:** README полностью переработан как продуктовая витрина с актуальными скриншотами React UI, выделением локальной приватности и понятным описанием трёх частей поставки;
- **Режим документации:** добавлен технический preview-режим для создания документационных скриншотов без отключения onboarding в обычном сценарии;
- **Улучшение CI:** добавлена возможность ручного запуска CI-пайплайна (`workflow_dispatch`) без создания пустых коммитов.

## Файлы релиза

- `VoxNote_0.2.3_x64-slim-setup.exe` — рекомендуемый лёгкий NSIS-установщик (~6,1 МБ);
- `VoxNote_0.2.3_x64-slim-setup.exe.sig` — цифровая подпись установщика;
- `latest.json` — подписанные метаданные для встроенного безопасного автообновления.

Модели Whisper и ML-runtime не входят в дистрибутив и загружаются только после явного выбора пользователя при первом запуске приложения.
