# VoxNote v0.2.4 — нативный экспорт заметок в .txt и .md

Этот patch-релиз устраняет проблему с экспортом заметок в текстовые файлы и документы Markdown на Windows.

## Что исправлено

- **Нативное окно сохранения файла:** при выборе «Обычный текст (.txt)» или «Документ Markdown (.md)» теперь вызывается системный проводник Windows «Сохранить файл» через библиотеку `rfd` вместо блокируемого веб-запроса WebView2;
- **Гарантия расширения и кодировки:** имя файла по умолчанию формируется из заголовка заметки, расширение `.txt` или `.md` подставляется и проверяется автоматически, а сохранение выполняется атомарно в UTF-8 без повреждения целевого файла;
- **Визуальная индикация:** после завершения экспорта кнопка «Экспортировать» на 2 секунды отображает подтверждение («Экспортировано!»).

## Файлы релиза

- `VoxNote_0.2.4_x64-slim-setup.exe` — рекомендуемый лёгкий NSIS-установщик (~4,0 МБ);
- `VoxNote_0.2.4_x64-slim-setup.exe.sig` — цифровая подпись установщика;
- `latest.json` — подписанный манифест безопасного встроенного обновления.

Модели распознавания Whisper и ML-runtime не входят в дистрибутив и загружаются локально только по выбору пользователя.
