# История изменений (Changelog)

Все заметные изменения в проекте VoxNote документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/), проект придерживается семантического версионирования.

## [Unreleased]

### Изменено
- Публичный релиз упрощён до одного slim-установщика; portable-сборки исключены из регулярного релизного цикла.
- Сборка приложения отделена от тяжёлой сборки ML-runtime и автоматизирована отдельным GitHub Actions workflow.
- README переработан как продуктовая витрина с актуальными скриншотами и понятным описанием выбора CPU, NVIDIA и моделей.
- Исторические release notes перенесены из корня репозитория в `docs/releases`.

## [0.2.2] - 2026-11-20

### Исправлено
- Активную транскрибацию больше нельзя скрыть переходом к новому файлу, истории, настройкам или обновлению приложения.
- Первый запуск повторяет подключение к Python-sidecar до его фактической готовности вместо фиксированной задержки.
- Перезапуск sidecar после установки NVIDIA-пакета защищён от гонки со старым watchdog-потоком.
- IPC-клиент регистрирует единственный слушатель сообщений даже при параллельных стартовых запросах.
- Системный drag-and-drop Tauri передаёт абсолютный путь аудиофайла вместо демонстрационного browser fallback.
- Значение `100%` отправляется только после успешного сохранения итоговой расшифровки.
- История синхронизирует конкурентные изменения и сохраняет резервную копию повреждённого JSON.
- Неполный NVIDIA runtime больше не считается установленным только по наличию каталога.

## [0.2.1] - 2026-11-20

### Добавлено
- В окно «Настройки» добавлена секция «Движок и ускорение»: пользователи, выбравшие базовый CPU-движок при первой установке, теперь могут в один клик доустановить пакет ускорения NVIDIA (CUDA ~667 МБ).
- Отображение прогресса, фаз и верификации контрольной суммы SHA-256 при установке GPU-пакета из настроек, а также автоматический перезапуск ядра с активацией видеокарты.

### Исправлено
- Исправлено зависание кнопки закрытия окна (крестик Windows): добавлены обязательные для Tauri 2 разрешения `core:window:allow-destroy` и `core:window:allow-close` в `capabilities/default.json` и продублирован нативный системный вызов.
- Устранена ошибка `TypeError` в автосохранении заметок при асинхронном обновлении истории.
- Стабилизированы тесты RichTextEditor и App в CI-окружении GitHub Actions.

## [0.2.0] - 2026-11-19

### Добавлено
- Легковесный подписанный установщик приложения: ML-движок и CUDA вынесены в отдельные версионные runtime-пакеты.
- Первый запуск предлагает CPU или NVIDIA, показывает реальный прогресс загрузки и позволяет отменить установку без активации неполного пакета.
- Runtime Manager проверяет разрешённый источник, размер и SHA-256 архива, защищает распаковку от выхода за целевой каталог и атомарно активирует готовый runtime.
- Добавлены отдельные CPU Portable и Full NVIDIA Portable, а также подписанный формат обновлений Tauri `latest.json`.

### Изменено
- Автоматическая проверка обновлений сохранена; загрузка и установка новой версии начинаются только после подтверждения пользователя.
- Production-оболочка больше не запускает случайный Python из системного `PATH` и использует только установленный или portable runtime.

### Исправлено
- CPU runtime на компьютере с NVIDIA больше не объявляет CUDA доступной без установленного accelerator pack.
- Транскрибация полностью тихого аудио завершается пустым результатом сразу после VAD, не запуская inference по пустым признакам и не зависая на `0%`.
- При отмене интерфейс сохраняет состояние «Отменяем…» до подтверждения от Python-sidecar.
- В dev-режиме Tauri запускает Python-sidecar из локального `.venv`, поэтому изменения ML-ядра больше не перекрываются устаревшим упакованным бинарником.
- Отмена системного выбора аудио или словаря больше не открывает следом второй диалог выбора файла.
- Быстрый профиль ограничивает runaway-декодирование шумного хвоста и использует greedy search вместо тяжёлого beam search.
- CUDA-модель больше не получает отдельный синтетический inference-прогрев перед пользовательским файлом: на текущем Windows/CTranslate2 он мог блокировать следующий запуск.
- В аудиоплеер добавлены регулятор громкости и быстрое отключение звука.
- Если backend не присылает прогресс 15 секунд, интерфейс явно сообщает о проверке зависшего состояния.
- Сбой локальной технической диагностики больше не прерывает финализацию и не скрывает готовую расшифровку от интерфейса.
- После анализа нового аудиофайла backend освобождает inspection-task до события готовности, поэтому следующая транскрибация больше не получает ложный `BUSY_ERROR`.
- При отмене уже распознанный текст и сегменты сохраняются в истории со статусом «Остановлено»; запись можно продолжить с сохранённой временной позиции без создания дубля.
- Экран обработки объясняет подготовку большого файла, показывает прошедшее время, реальную модель и вычислительное устройство; ETA появляется после накопления достаточных данных.
- Параметры модели, устройства и словаря блокируются в контексте сохранённой записи и во время обработки, а техническое `cuda` заменено понятным названием видеокарты.
- Из внутренней верхней панели удалены дубли нативных кнопок окна Windows; элементы управления сгруппированы и снабжены понятными состояниями.
- На пустом экране скрыта неактуальная правая колонка экспорта, таймлайна и плеера; она появляется только после выбора аудиозаписи.
- Из верхней панели удалены дублирующая проверка обновлений и отдельный информационный значок; проверка обновлений остаётся в боковой панели.
- Добавлен отдельный главный экран с локальной сводкой, последними записями и быстрым продолжением остановленной транскрибации.
- Логотип VoxNote возвращает на главный экран, а открытую заметку можно закрыть отдельной кнопкой без её удаления.
- До появления текста правая панель показывает только аудиоплеер; экспорт, редактирование и таймлайн появляются после получения расшифровки.
- Частичные сегменты атомарно сохраняются во время inference; после аварийного завершения запись помечается «Прервана» и может быть продолжена.
- Закрытие окна во время транскрибации предлагает остаться либо безопасно остановить задачу, сохранить частичный текст и закрыть приложение.
- Экран обработки явно различает чтение файла, загрузку модели, анализ тишины, распознавание и сохранение результата.
- Потерянный исходный аудиофайл не скрывает текст заметки: плеер и продолжение блокируются до выбора нового расположения файла.
- Поиск в библиотеке явно обозначен как поиск по записям и распознанному тексту; на Home исправлена подпись общей длительности.
- Индикатор этапов обработки упрощён до аккуратной линии прогресса; техническое слово ETA удалено из пользовательских подписей.
- Расчёт оставшегося времени больше не сбрасывается на скачках VAD и использует консервативную среднюю скорость при редких сегментах.
- Словари больше не обрезаются до первых 30 терминов: полный список передаётся faster-whisper через `hotwords`, а выбор словаря ожидает подтверждения backend.
- Настройки темы и снижения анимаций загружаются и сохраняются через sidecar; ручной reduced motion отключает CSS-анимации независимо от Windows.
- «История правок» хранит до 20 предыдущих локальных версий текста с возможностью восстановления.
- При перепривязке исходного аудио проверяется длительность, поэтому явно другая запись не может быть выбрана молча.
- Реальный CUDA crash-smoke на 95-минутном аудио подтвердил восстановление одного сегмента и позиции продолжения после принудительного завершения изолированного worker.

## [0.1.2] — 2026-11-19

### Исправлено
- **Параметр запуска транскрибации**: в `SidecarService.start_transcription` добавлен приём аргументов `device` и `device_preference`, устранена ошибка `unexpected keyword argument 'device'`.
- **Отрисовка волны (Waveform)**: динамическая нормализация амплитуд аудиосигнала [0.0, 1.0] от PyAV, устранено схлопывание столбиков волны в плоскую линию.
- **Воспроизведение аудио**: плеер в боковой панели активируется сразу при выборе аудиофайла в «Новом файле», в карточку файла добавлена кнопка Play/Pause предпрослушивания.
- **Интерфейс обновлений**: кнопка «Обновления» добавлена в верхнюю панель TopBar, а в боковой панели вынесена в отдельную строку с полноценной подписью.

## [0.1.1] — 2026-11-18

Выпуск с устранением технического долга, ликвидацией всех mock-заглушек и полной стабилизацией сквозного пользовательского пути.

### Исправлено
- **Зацикливание транскрибации**: устранён искусственный интервальный таймер в UI; транскрибация теперь выполняет реальный вызов ML-ядра faster-whisper через JSON-RPC.
- **Воспроизведение аудио**: аудиоплеер переведён на нативное воспроизведение через протокол `assetProtocol` Tauri 2 (`convertFileSrc`), исправлены кнопка Play/Pause, перемотка по клику на волну и прыжок по таймкодам сегментов речи.
- **Статический конспект GoodNotes**: удалены хардкодные блоки-заглушки («Краткое содержание», «Ключевые тезисы»), заменены на реальный редактируемый текст распознавания, статистику слов/символов и форматирование Markdown.
- **Автозагрузка старого файла**: при старте приложения открывается чистый экран выбора новой аудиозаписи, а не случайная архивная запись.
- **Удаление записей**: добавлена возможность удаления лекций из истории как через боковую панель, так и из открытой заметки с подтверждением.

### Добавлено
- **Система проверки обновлений**: модальное окно `UpdateModal` с проверкой GitHub Releases, прямыми ссылками на скачивание свежих установщиков и портативных архивов.
- **Интерактивная загрузка моделей**: отображение реального прогресса загрузки весов моделей в процентах и байтах с кнопкой отмены и удаления.
- **Нативный проводник Windows**: выбор аудиофайлов и словарей через системный диалог `rfd` и перетаскивание с определением абсолютных путей.
- **Нативное управление окном**: кнопки «Свернуть», «Развернуть» и «Закрыть» подключены к командам окна Tauri.

## [0.1.0] — 2026-11-18

Первый публичный MVP-релиз десктопного приложения VoxNote для Windows 10/11 x64.

### Добавлено

#### Пользовательский интерфейс (Концепт A: «Сфокусированное рабочее пространство»)
- **Трёхколоночная архитектура лекций и конспектов:**
  - Левая панель навигации (библиотека заметок, группировка «Сегодня», «На этой неделе», «Ранее», быстрый поиск `Ctrl+K`, кнопка `+ Новый файл` `Ctrl+N`).
  - Центральная область конспекта с редактируемым названием, метаданными (длительность, модель, словарь), вкладками «Конспект», «Транскрипт» и «История версий».
  - Правая панель действий: мгновенный экспорт в UTF-8 `.txt` и Markdown `.md`, копирование в буфер, таймлайн распознанных сегментов с кликабельными таймкодами и аудиоплеер с амплитудной звуковой волной.
- **Вступительная инструкция («Как устроен VoxNote»):**
  - Интерактивный трёхколоночный гид при первом запуске и по кнопке «Инструкция» в боковой панели.
  - Описание горячих клавиш (`Ctrl+K`, `Ctrl+N`) и гарантии 100% приватности без отправки данных в сеть.
- **Выбор каталога для загрузки моделей:**
  - Настройка пользовательского пути к весам моделей прямо из окна «Модели распознавания» с возможностью сброса к системному `%LOCALAPPDATA%\VoxNote\models`.
- **Выбор каталога установки:**
  - Возможность выбора любого диска и папки при установке приложения через Windows NSIS Installer.
- **Светлая, тёмная и системная темы:**
  - Фирменная палитра Концепта A (шалфейный акцент `#577A5B`, тёплый фон `#F7F3EE`, контрастные поверхности карточек).
  - Поддержка режима снижения анимаций (`prefers-reduced-motion`).

#### ML-ядро и транскрибация
- **Локальный движок faster-whisper / CTranslate2:**
  - Поддержка русской речи, VAD-фильтрация (Silero VAD) для отсечения шума и пауз.
  - Модели MVP: `small` («Быстрая»), `turbo` («Сбалансированная»), `large-v3` («Максимальная точность»).
  - Докачка моделей по частям с проверкой целостности SHA-256.
- **Аппаратное ускорение NVIDIA GPU:**
  - Автоматическое определение совместимых карт NVIDIA CUDA, загрузка официальных DLL wheels (`cublas`, `cudnn`, `nvrtc`) без модификации системного `PATH`.
  - Безопасный режим «Авто» с предварительной проверкой и CPU-fallback при отсутствии совместимой видеокарты.
- **Аудиопайплайн PyAV:**
  - Декодирование форматов `.m4a`, `.mp3`, `.wav`, `.flac`, `.ogg` без внешних утилит ffmpeg.
  - Расчет метаданных и амплитудных пиков звуковой волны.
- **Честный прогресс и сглаженный ETA:**
  - Прогресс строго по временным меткам распознанной речи.
  - Медианный сглаженный расчет оставшегося времени без ложных 100% до финализации.
- **Терминологические словари:**
  - Встроенный проверенный медицинский словарь (`medical-ru`) на 1847 терминов.
  - Импорт собственного UTF-8 `.txt` словаря с валидацией, дедупликацией и лимитом в 1000 терминов.
  - Подсказка через контекст модели без разрушительной автозамены.
- **Хранилище истории и библиотека:**
  - До 50 заметок с поиском и безопасной ротацией (заметки с правками защищены от автоудаления).
  - Раздельное хранение оригинального текста и правок пользователя.
- **100% Приватность:**
  - Полностью локальная обработка: нулевая телеметрия, отсутствие сетевых запросов во время работы с аудио.
